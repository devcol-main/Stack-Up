선행: Task 001 (브랜치 `task/001-stack-up` 위에서 진행)
규칙: `CLAUDE.md`. **에셋은 무료 + 상업적 사용 가능한 것만** (라이선스를 `docs/assets.md`에 기록). 이번 Task는 외부 에셋 없이 코드 합성으로 해결한다.

## 요청 사항
1. **BGM 추가**
2. **Perfect VFX 변경**: 원형 링 대신 **큰 네모(사각형) 파동**. 화면 상단의 `PERFECT` 텍스트도 더 크게
3. **옵션 설정**
4. **내 Best Score 표시**
5. **Perfect 허용치 소폭 상향**
6. **층수 마일스톤 Feedback**: 5, 10, 20, 30 … (이후 10 단위) 층 도달 시

## 상세
### 1. BGM
- WebAudio 합성 루프(아르페지오 + 베이스 패턴). 외부 음원 파일 없음.
- 첫 사용자 입력 이후 시작, 탭이 숨겨지면 정지/복귀 시 재개(기존 suspend/resume 경로 사용).
- 게임 오버 시 볼륨을 낮추거나 정지, 재시작 시 복귀. 층이 올라가면 템포/음 변화는 선택(과하지 않게).
- 효과음과 별도로 켜고 끌 수 있고 볼륨이 분리된다. 기본 BGM 볼륨은 효과음보다 낮게.

### 2. Perfect VFX / 텍스트
- 기존 링(타원) 연출을 **블록 모양을 따르는 사각형 외곽선 파동**으로 교체: 블록 위치에서 시작해 바깥으로 크게 퍼지며 페이드. 콤보가 높을수록 더 크게(상한 있음).
- 입자는 유지. reduced motion이면 크기/입자 축소(기존 정책 유지).
- 상단 `PERFECT` 텍스트 크기 확대(현재 대비 눈에 띄게, 좁은 화면에서 넘치지 않게).

### 3. 옵션
- 타이틀 및 일시적으로 접근 가능한 **옵션 패널** (HTML 오버레이, 모든 텍스트 영어).
- 항목: BGM On/Off, SFX On/Off, 볼륨 슬라이더(BGM / SFX 각각), Reduced motion 수동 토글(OS 설정과 OR 관계: 둘 중 하나라도 켜면 축소), 데이터 초기화(최고 기록 + 닉네임 삭제, 확인 단계 포함. 리더보드 Local 데이터는 건드리지 않는다).
- 설정은 localStorage 저장(항상 try/catch, 사용 불가여도 동작). 기존 음소거(M키/버튼)와 일관되게 통합: M키는 BGM+SFX 전체 음소거 토글로 유지.
- 플레이 중에는 옵션을 열 수 없고(실수 방지), 타이틀/게임 오버 화면에서 연다. 옵션 패널이 열린 동안 게임 입력은 무시.

### 4. Best Score
- 플레이 중 HUD(점수 근처, 작게)와 타이틀에 `BEST n` 표시. 신기록 갱신 시 게임 오버 화면에 `NEW BEST` 표시.
- 기존 최고 기록 저장소(`stackup.best`) 재사용.

### 5. Perfect 허용치
- 폭 비율 3% → **4.5%**, 최소 하한 0.004 → **0.006**. 값은 `config.ts`에서만 수정. 경계값 테스트도 갱신.

### 6. 마일스톤 Feedback
- 기준: **층수**. 5층, 이후 10, 20, 30 … (10 단위)에 도달할 때. 기존 Perfect 콤보 5 단위 폭 회복 연출은 그대로 둔다.
- core가 `milestone`(level) 이벤트를 낸다 (한 drop에 최대 1개, 게임 오버 drop에서는 내지 않음).
- 형태: ① 화면 텍스트 팝업(예: `10 FLOORS!`, 영어, 큰 글씨 + 글로우, 페이드), ② 전용 사운드(합성), ③ 배경 색 플래시(화면 전체가 잠깐 밝아짐; reduced motion이면 생략 또는 약하게).

## 하위 작업 순서
1. core: Perfect 허용치 상향, `milestone` 이벤트 + 테스트
2. view: 사각형 Perfect 파동, 배경 플래시(마일스톤)
3. audio: BGM 합성 루프, 마일스톤 사운드, BGM/SFX 분리 + 볼륨 (순수 로직 테스트)
4. UI: 옵션 패널, 설정 저장, Best Score(HUD/타이틀/NEW BEST), 마일스톤 텍스트 팝업, 상단 PERFECT 확대
