## 상세
### 1. 로고
- 파일은 저장소에 포함(외부 URL 금지): `games/stack-up/src/assets/devcol-logo.png`로 복사. `docs/assets.md`에 기록(출처, "DevCol 소유 로고", 사용처).
- **위치(2026-10-13 사용자 요청으로 변경)**: 타이틀/게임 오버 화면 중앙이 아니라 **모든 화면의 좌상단**에 로고 하나만 표시(타이틀, 플레이, 게임 오버 공통). 플레이 중 `STACK UP` 문구는 **상단 가운데 정렬**(점수 바로 위, 2026-10-13 사용자 요청)로 둔다(로고는 좌상단 유지). 우상단 Sound/Options 버튼과 겹치지 않게, 좁은 폭/낮은 높이/안전 영역(`env(safe-area-inset-*)`)을 고려한다.
- **색(2026-10-13 사용자 요청으로 변경)**: 검정 로고를 CSS `invert/hue-rotate` 필터로 뒤집으면 훅이 원본 빨강이 아니라 살몬색이 되어 어색하다. 대신 **어두운 배경용 변형 이미지**(`devcol-logo-dark.png`)를 원본에서 파생한다: 어두운 픽셀(검정 네모)은 흰색으로, 빨강 훅은 원본 색 그대로, 알파 유지. 필터는 쓰지 않는다. 파비콘은 원본 로고를 유지한다. 변형 이미지의 생성 방법과 출처를 `docs/assets.md`에 기록.
- **파비콘**: `index.html`에 `<link rel="icon">` (같은 로고, 번들 포함).
- 접근성: `alt` 텍스트 `DevCol logo`(영어). 로드 실패해도 게임이 돌아가야 한다. 로고는 입력(탭/Space)을 가로채지 않는다(타이틀의 첫 탭은 시작 동작 유지).
- reduced motion 영향 없음(정적 이미지). 빌드 용량 한도(300KB) 유지.

### 2. README 미디어
- 파일 위치: `docs/media/` (저장소에 포함). README에서 상대 경로로 참조.
- 정지 이미지(PNG, 세로 모바일 비율): 타이틀, 플레이 중(타워가 어느 정도 쌓인 모습 + Perfect 파동 또는 마일스톤), 게임 오버(Top 10), 옵션 패널.
- GIF 1개: 플레이 장면(블록 이동 → 안착 → Perfect 연출 → 쌓임 → 마지막에 자르기/게임 오버), 약 20~25초(10층 마일스톤과 카메라 상승, 콤보 5 폭 회복 장면 포함), 파일 크기 8MB 이하 목표(초과 시 폭/fps/색상 수를 낮춤). 길이와 용량 기준은 2026-10-13에 사용자 확인으로 확대함(처음의 8~10초/5MB는 명세 작성자의 임의 값이었음).
- 캡처는 **재현 가능한 스크립트**로 만든다(`scripts/capture-media.mjs`): 로컬 Chrome을 헤드리스로 띄워 CDP(WebSocket, 의존성 추가 없음)로 조작하고 `ffmpeg`로 GIF 인코딩. 시드 고정으로 같은 결과. 자동 플레이 봇은 캡처 스크립트 쪽에만 둔다(게임 코드에 AI 추가 금지). 봇이 로직 상태를 읽을 수 있도록 **개발 모드에서만** `window.__stackUp`을 노출하는 최소 훅 허용(`import.meta.env.DEV`로 가드, 프로덕션 번들에 남지 않아야 한다).
- README 상단에 대표 이미지/GIF를 넣고, 기능 설명 부근에 정지 이미지들을 배치. 이미지에는 대체 텍스트(영어).
