## 문제
옵션 패널을 열면 패널 뒤의 화면(타이틀의 `Tap, click or press Space to drop the block` 안내, 큰 `STACK UP` 제목, `BEST` 등)이 어둡게 비쳐서 패널의 행("Reduced motion" 등)과 겹쳐 보인다. (`docs/media/options.png`에서 확인됨)

## 요구
- 옵션 패널이 열려 있는 동안 패널 뒤의 화면 텍스트가 패널 내용과 겹쳐 보이지 않게 한다. 배경 오버레이를 사실상 불투명하게 하거나(알파 상향), 패널이 열린 동안 뒤쪽 `.screen` 내용을 숨기는 방식 중 가장 단순하고 안전한 쪽을 택한다. 캔버스(블록/별/그리드)는 어둡게 비쳐도 무방(분위기 유지).
- 패널을 닫으면 원래 화면이 그대로 복귀(상태/포커스/입력 처리 불변). 타이틀·게임 오버 양쪽에서 확인.
- reduced motion, 키보드(Tab/Esc), 닫을 때 입력 누수 방지 등 기존 동작 불변.
- README 스크린샷 `docs/media/options.png`를 재생성(`npm run media`)해 반영.
